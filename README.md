# My Personal Portfolio - ICT251 Activity 3

My name is Mainza Hachilensa. This is my interactive student portfolio built for the ICT251 Web Technologies course. This website was developed using HTML5, CSS3, and vanilla JavaScript.

## JavaScript Features Implemented
1. **Theme Switch:** A button that toggles the website between Dark Mode and Light Mode.
2. **Mobile Navigation:** A responsive menu button that appears on small screens to open/close navigation links.
3. **Expandable Projects:** A "Show Details" button on the Projects section that reveals or hides project information.
4. **Contact Form Validation:** Client-side validation for the contact form. It rejects empty fields or invalid email formats and shows a preview of the data on the page without reloading.

## How to Test
- Open the live site in a web browser.
- Click the glowing "Dark/Light" button in the top right corner to switch themes.
- Resize the browser window to a narrow width to reveal the mobile menu button.
- Try submitting the contact form with empty or invalid data to see the validation messages.
